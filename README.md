# 🚀 PPT Maker — A branch of DocuCraft Studio

> **Autonomous, Aesthetic Presentation Generator & PowerPoint (.pptx) Exporter**

![DocuCraft Studio PPT Maker](/src/assets/hero.png)

**DocuCraft Studio: PPT Maker** is a next-generation web application designed to create, customize, and present stunning slide decks in seconds, and export native, fully-editable PowerPoint (`.pptx`) files.

---

## ✨ Features & Highlights

### 🎨 9 Aesthetic Preset Themes
- **DocuCraft Signature:** Obsidian deep sapphire with electric blue highlights.
- **Sleek Tech:** Indigo & slate modern aesthetic.
- **Sunset Glow:** Rose gold, coral, and deep purple gradient vibe.
- **Cyberpunk Neon:** Vibrant pinks and neon accents.
- **Warm Editorial:** Classic terracotta, cream background, and serif typography.
- **Pastel Nordic:** Clean sage, teal, and soft minimalist whites.
- **Midnight Aurora:** Obsidian dark with emerald green highlights.
- **Executive Slate:** Professional corporate navy blue and silver platinum.
- **Swiss Brutalist:** High-contrast monochrome with bold yellow highlights.

### 📐 9 Flexible Slide Layouts
1. **Title Slide:** High-impact hero headlines and category tags.
2. **Bullets Content:** Clean list layouts with custom checkmarks.
3. **Split Columns:** Two-column topic or side-by-side comparison cards.
4. **Metric Stat Callout:** Big stat values with supporting subtext and key highlights.
5. **Quote / Endorsement:** Testimonial blocks with author and organization details.
6. **Roadmap Timeline:** 3-stage milestone sequence.
7. **Matrix Comparison:** Pros vs. Cons or Option A vs. Option B comparison cards.
8. **2x2 Feature Grid:** Four capability card grid layout.
9. **Team Showcase:** Leader and speaker profile cards with avatar badges.

### ⚡ Power Features & Customization
- **Native PowerPoint (.pptx) Export:** Powered by `pptxgenjs`, exporting fully editable vector shapes, formatted text blocks, and colored containers.
- **Slide Search & Quick Filter:** Real-time search bar across slide titles, tags, and content.
- **Aspect Ratio Switch:** Widescreen (`16:9`) and Standard (`4:3`) preview and export support.
- **Custom Color & Typography Overrides:** Color picker for accent overrides per slide and font family selector (Sans, Serif, Mono).
- **Fullscreen Presenter Mode:** Includes presenter clock timer, dot navigation, aspect ratio support, and keyboard controls (`ArrowRight`, `ArrowLeft`, `Space`, `Escape`).
- **Quick Layout Generator Modal:** One-click insertion of pre-designed slide components.
- **Confetti & Toast Feedback:** Visual notifications on export and deck loading.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v3
- **Icons:** Lucide React (`lucide-react`)
- **Exporting Engine:** `pptxgenjs` (PowerPoint PPTX Generation)
- **Effects:** `canvas-confetti`
- **Linter & Build:** Oxlint + Vite

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/ppt-maker-docucraft-studio.git

# Navigate into project directory
cd ppt-maker-docucraft-studio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build & Lint

```bash
# Production Build
npm run build

# Run Oxlint
npm run lint
```
